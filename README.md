# Projeto 22:50

Mini app para acompanhar preparação para 5 km em 22:50.

Inclui:
- peso diário e tendência de 7 dias;
- dieta e calorias por tipo de treino;
- rotina semanal até a prova;
- musculação e pliometria;
- biomecânica da perna direita;
- análise dos 8 Reels com reprodução incorporada;
- biblioteca de exercícios recomendados;
- check-ins e dados salvos no navegador.

A publicação no GitHub Pages é feita pelo workflow em `.github/workflows/pages.yml`.

> O app é uma ferramenta de organização e não substitui acompanhamento profissional individual.
